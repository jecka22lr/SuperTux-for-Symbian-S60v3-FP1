# SuperTux 0.1.3 for Symbian S60v3 FP1
A port of SuperTux 0.1.3 for Symbian S60v3 FP1 and later devices. 240x320. Not my own work - only modified it so I could use the dependencies I could not match for the original port to build it. AI ASSISTED - Claude assisted some of the changes in this port to make it work.

# What changed?
Dependencies - instead of PIPS 1.3, OpenC (a more modern implementation)
Some code - adjusted to the dependencies I could work with, because the original source modified the code confusingly and not all the libraries or dependencies used were present

# How to install?
As of release 1, you should be able to just install it without needing anything else, as this package is signed properly and OpenC is bundled. Make sure you have enough free space on your phone and/or card for the installer, game itself, and data (like save files).

# Requirements
I have not tested this on enough devices, but the target is the Nokia N82 and N95, which both share the same internals (332 Dual ARM CPU and 3d accelerated GPU HW rendering.)
